## 给 AI 的步骤（带用户用示例数据搭个演示时照这个顺序；用户自己会用的话，直接下载组件导入就行）

按顺序做，一步都不要跳。第 1、2 步直接做完，中间不用停，做完报结果；第 3、4 步要在 Power BI 界面里点，AI 没权限替用户操作，每步告诉用户怎么点，等用户回复再做下一步。

1. **下载**：本仓库 main 分支的 `downloads/calendar-heatmap.pbiviz` 和 `sample-data/` 里的 3 个 csv，存到当前的工作文件夹（不要放「下载」），报出每个文件的完整路径。
2. **建文件、接数据**：有 Power BI MCP 和 skill（如微软 `powerbi-authoring` 插件）就新建一个 PBIP 项目，导入 3 张表，建关系（销售明细[门店ID] → 门店[门店ID]，销售明细[产品ID] → 产品[产品ID]），建度量值 `销售额 = SUM('销售明细'[销售额])`，告诉用户项目存在哪、双击 `.pbip` 打开；没有就一步步教用户在 Power BI Desktop 里新建文件，用「获取数据 → 文本/CSV」导入并建好这些。
3. **导入组件**：等用户在 Power BI Desktop 里打开这个文件，再告诉用户点：可视化窗格「…」→ 从文件导入视觉对象 → 选第 1 步的 `calendar-heatmap.pbiviz`。组件只导入到当前打开的报表，所以要在第 2 步的文件里导。等用户确认导入好了再继续。
4. **放字段**：「销售明细」的「日期」拖到「日期」框（右键选「日期」，不是「日期层次结构」），「销售额」拖到「数值」框。

## 日历热力图怎么用（给人看的）

1. Power BI Desktop → 可视化窗格 → 点「…」→ 从文件导入视觉对象 → 选 `calendar-heatmap.pbiviz`。
2. 导入 `sample-data` 里的 3 张表（销售明细、门店、产品），建一个度量值 `销售额 = SUM('销售明细'[销售额])`。
3. 「销售明细」的「日期」拖到「日期」框：在字段上右键选「日期」，不要用「日期层次结构」。
4. 「销售额」拖到「数值」框。
5. 悬停看每天的数；点格子筛选同页其他图，Ctrl 多选，点空白处取消；格式面板里能改：颜色（默认跟随报表主题）、周一开始、显示月份、格子圆角、字体字号和文字颜色（默认跟随报表主题）、图例（位置、色块大小和个数、两端显示文字或最小/最大值）。

## 它做了什么、没做什么

- 只在你的 Power BI 里画图，不联网，不收集、不上传任何数据。
- 没有经过微软认证。公司电脑如果禁止未认证的视觉对象，会导入不了或显示不出来，先问问 IT。

## 哑铃图、华夫饼图、南丁格尔玫瑰图、子弹图、帕累托图、排名变化图、图片卡片墙怎么用

先导入 sample-data 的 3 张表，子弹图再加「目标」（目标[门店ID] → 门店[门店ID]），图片卡片墙再加「产品图片」（产品图片[产品ID] → 产品[产品ID]，一对一）。建度量值：

```
销售额 = SUM('销售明细'[销售额])
2024 销售额 = CALCULATE([销售额], YEAR('销售明细'[日期]) = 2024)
2025 销售额 = CALCULATE([销售额], YEAR('销售明细'[日期]) = 2025)
目标销售额 = SUM('目标'[目标销售额])
同比 = DIVIDE([2025 销售额], [2024 销售额]) - 1
```

排名变化图还要在销售明细里新建一列 `月份 = MONTH('销售明细'[日期]) & "月"`。

| 组件 | 类别 | 数值 |
|---|---|---|
| 哑铃图 | 门店[门店] | 起点 = 2024 销售额，终点 = 2025 销售额 |
| 华夫饼图 | 产品[品类] | 数值 = 销售额 |
| 南丁格尔玫瑰图 | 门店[门店] | 数值 = 2025 销售额 |
| 子弹图 | 门店[门店] | 实际 = 2025 销售额，目标 = 目标销售额 |
| 帕累托图 | 产品[产品] | 数值 = 2025 销售额 |
| 排名变化图 | 类别 = 产品[产品]，时间 = 销售明细[月份] | 数值 = 2025 销售额 |
| 图片卡片墙 | 类别 = 产品[产品]，图片 = 产品图片[图片]，小字说明 = 产品[品类] | 主数值 = 2025 销售额，副数值 = 同比（格式设成百分比） |

这几个组件颜色都默认跟随报表主题，悬停显示数值，点选交叉筛选；同样不联网、没有经过微软认证。
