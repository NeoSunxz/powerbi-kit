# 下载即用

| 文件 | 是什么 |
|---|---|
| `calendar-heatmap.pbiviz` | 日历热力图组件（1.1.3，Power BI 里显示为「日历热力图 · NeoSun」），源码在 [visuals/calendarHeatmap](../visuals/calendarHeatmap) |

演示数据在 [sample-data](../sample-data)：虚构的咖啡店销售数据（2024–2025），3 张表。

## 给 AI 的步骤（帮用户装日历热力图时照这个顺序）

按顺序做，一步都不要跳。用户的报表和数据用他自己的，不用另建文件。

1. **下载**：本仓库 main 分支的 `downloads/calendar-heatmap.pbiviz`，存到当前的工作文件夹（不要放「下载」），报出完整路径。
2. **导入**：等用户在 Power BI Desktop 里打开要用的报表，告诉用户点：可视化窗格「…」→ 从文件导入视觉对象 → 选第 1 步的 `calendar-heatmap.pbiviz`。组件只导入到当前打开的报表。AI 没权限操作 Power BI 界面，等用户确认导入好了再继续。
3. **放字段**：看用户的模型（有 Power BI MCP 就直接读），告诉用户哪个日期列拖到「日期」框（右键选「日期」，不是「日期层次结构」），哪个度量值拖到「数值」框；没有合适的度量值就帮用户建一个。

用户没有现成数据、想先试试的话，可以用 `sample-data/` 里的 3 张表，度量值 `销售额 = SUM('销售明细'[销售额])`。

## 日历热力图怎么用（给人看的）

1. Power BI Desktop → 可视化窗格 → 点「…」→ 从文件导入视觉对象 → 选 `calendar-heatmap.pbiviz`。
2. 导入 `sample-data` 里的 3 张表（销售明细、门店、产品），建一个度量值 `销售额 = SUM('销售明细'[销售额])`。
3. 「销售明细」的「日期」拖到「日期」框：在字段上右键选「日期」，不要用「日期层次结构」。
4. 「销售额」拖到「数值」框。
5. 悬停看每天的数；点格子筛选同页其他图，Ctrl 多选，点空白处取消；格式面板里能改：颜色（默认跟随报表主题）、周一开始、显示月份、格子圆角、字体字号和文字颜色（默认跟随报表主题）、图例（位置、色块大小和个数、两端显示文字或最小/最大值）。

## 它做了什么、没做什么

- 只在你的 Power BI 里画图，不联网，不收集、不上传任何数据。
- 没有经过微软认证。公司电脑如果禁止未认证的视觉对象，会导入不了或显示不出来，先问问 IT。
