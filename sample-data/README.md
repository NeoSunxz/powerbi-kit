# 示例数据（公开数据）

演示、截图、录屏一律用这里的数据，不用工作文件。

| 文件 | 内容 | 来源 |
|---|---|---|
| `cpi_monthly_yoy.csv` | 2016-01 到 2026-09 每月 CPI 同比（%），含总体、核心和 8 大类 | 国家统计局 |
| `income_q1q3.csv` | 2016–2026 年每年前三季度全国居民人均可支配收入、中位数（元） | 国家统计局 |

- 同比是百分数：`2.0` 表示比去年同月涨 2.0%。
- 「居住」不含买房价格，只算房租、水电、物业等。
- 「其他用品和服务」里有金饰，波动大，单独展示时要说明。
- 数据通过个人工具从公开渠道整理，和统计局官网可能有小数点后的差别。
