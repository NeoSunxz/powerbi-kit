# 示例数据（虚构）

一家虚构的连锁咖啡店，2024–2025 两年的销售数据。**全部是程序随机生成的，不对应任何真实公司**，演示、截图、录屏一律用这份，不用工作文件，也不用财经数据。

| 文件 | 内容 |
|---|---|
| `销售明细.csv` | 每天 × 门店 × 产品的杯数和销售额（元） |
| `门店.csv` | 6 家门店：门店ID、门店、区域、门店类型 |
| `产品.csv` | 10 个产品：产品ID、产品、品类、单价 |

用法：三张表都导入 Power BI，`销售明细[门店ID]` 连 `门店[门店ID]`，`销售明细[产品ID]` 连 `产品[产品ID]`；再建一张日期表连 `销售明细[日期]`。

数据里埋了几个能看出来的规律，方便演示：写字楼店周末少、商场店周末多，校园店寒暑假少，冬天咖啡卖得多、夏天茶饮多，整体两年慢慢上涨。
