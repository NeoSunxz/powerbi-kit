# 日历热力图（Power BI 自定义视觉对象）

一行一年，一格一天，颜色越深数值越大。用 D3 画 SVG。

- 字段：「日期」放一个日期字段（右键选「日期」，不要用「日期层次结构」），「数值」放一个度量值。
- 交互：悬停显示 Power BI 原生提示框；点格子交叉筛选其他图，Ctrl 多选，点空白处取消；右键菜单。
- 颜色：默认跟随报表主题——最大值取主题第一个数据颜色（深色主题下自动提亮、提饱和度，越多越亮），最小值从卡片底色往最大值渐变，没有数据的日子比底色稍亮；关掉「跟随报表主题」可自己选最小值 / 最大值 / 没有数据的日子的颜色。高对比度模式用系统颜色。
- 格式面板：周一开始、显示月份、格子圆角；文字（字体、字号、加粗、颜色；颜色默认跟随报表主题，取主题的次要文字色 secondLevelElements，和自带图的图例、坐标轴标签一样，主题没设就是 #605E5C）；图例（显示、位置、两端显示「少 / 多」或最小 / 最大值、两端文字、色块大小、色块个数、文字大小）。
- 安全：不联网（privileges 为空）、不存数据；代码里不用 innerHTML / eval，文字都用 D3 的 .text() 写入。（打包后的文件里能搜到 innerHTML，那是 D3 库自带的 .html() 方法，本组件没有调用。）

## 自己打包

```
npm install
npx pbiviz package          # 输出在 dist/
```

需要 Node.js 18+。`pbiviz.json` 里的作者邮箱用 GitHub noreply 地址，supportUrl 指向本仓库。
