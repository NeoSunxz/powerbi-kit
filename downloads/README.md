# 下载即用

| 文件 | 是什么 |
|---|---|
| `calendar-heatmap.pbiviz` | 日历热力图组件（测试版 1.0），源码在 [visuals/calendarHeatmap](../visuals/calendarHeatmap) |

演示数据在 [sample-data](../sample-data)：虚构的咖啡店销售数据（2024–2025），3 张表。

## 给 AI 的步骤（帮用户装日历热力图时照这个顺序）

按顺序做，一步都不要跳；每步做完先告诉用户结果，等用户回复再做下一步。

1. **下载**：本仓库 main 分支的 `downloads/calendar-heatmap.pbiviz` 和 `sample-data/` 里的 3 个 csv，存到用户的「下载」文件夹，报出每个文件的完整路径。
2. **建文件、接数据**：有 Power BI MCP 和 skill（如微软 `powerbi-authoring` 插件）就新建一个 PBIP 项目，导入 3 张表，建关系（销售明细[门店ID] → 门店[门店ID]，销售明细[产品ID] → 产品[产品ID]），建度量值 `销售额 = SUM('销售明细'[销售额])`，告诉用户项目存在哪、双击 `.pbip` 打开；没有就一步步教用户在 Power BI Desktop 里新建文件，用「获取数据 → 文本/CSV」导入并建好这些。
3. **导入组件**：等用户在 Power BI Desktop 里打开这个文件，再告诉用户点：可视化窗格「…」→ 从文件导入视觉对象 → 选第 1 步的 `calendar-heatmap.pbiviz`。组件只导入到当前打开的报表，所以要在第 2 步的文件里导。等用户确认导入好了再继续。
4. **放字段**：「销售明细」的「日期」拖到「日期」框（右键选「日期」，不是「日期层次结构」），「销售额」拖到「数值」框。

## 日历热力图怎么用（给人看的）

1. Power BI Desktop → 可视化窗格 → 点「…」→ 从文件导入视觉对象 → 选 `calendar-heatmap.pbiviz`。
2. 导入 `sample-data` 里的 3 张表（销售明细、门店、产品），建一个度量值 `销售额 = SUM('销售明细'[销售额])`。
3. 「销售明细」的「日期」拖到「日期」框：在字段上右键选「日期」，不要用「日期层次结构」。
4. 「销售额」拖到「数值」框。
5. 悬停看每天的数；点格子筛选同页其他图，Ctrl 多选，点空白处取消；格式面板里能改：颜色（默认跟随报表主题）、周一开始、显示月份、格子圆角、字体字号和文字颜色、图例（位置、色块大小和个数、两端显示文字或最小/最大值）。

## 它做了什么、没做什么

- 只在你的 Power BI 里画图，不联网，不收集、不上传任何数据。
- 没有经过微软认证。公司电脑如果禁止未认证的视觉对象，会导入不了或显示不出来，先问问 IT。
